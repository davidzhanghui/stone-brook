What it does

一块块内容，垒成一篇文档

文档由块组成：段落、表格、代码是块，画板、表格、多维表格也是块。双击一个嵌入块，它就展开成全屏编辑器。

文档编辑

六级标题、多级列表与待办、引用、高亮块、分栏、图片裁剪；Markdown 快捷语法随手生效，/ 菜单支持拼音。

19 种语言高亮评论同步块模板

粘贴与导出

从网页复制，标题、列表、表格、代码块原样还原；复制时同时写出 HTML 和 Markdown。

导入 Markdown导出 MD / HTML / PDF

图表与公式

自研 Mermaid 风格渲染器，不依赖浏览器：流程、时序、类、状态、ER、甘特、饼图、思维导图、时间线；KaTeX 公式。

9 类图表块级 / 行内公式

画板

图形、连线、便签、分区、泳道、画笔、思维导图；Mermaid / PlantUML 一键转成可编辑图形。

60 个模板约 2.3 万个素材

草图

Excalidraw 兼容的手绘白板：箭头绑定、容器文字、框架。存储就是官方 .excalidraw 格式。

与官网剪贴板互通Obsidian 文件

电子表格

IronCalc 公式引擎，改一个数相关格子自动重算；条件格式、数据验证、下拉列表、冻结、多工作表。

497 个函数xlsx / CSV

多维表格

21 种字段、公式与关联引用；表格、看板、画册、甘特、日历、表单六种视图，行列双向虚拟滚动。

网页卡片、视频、文件附件（代码 / PDF / Office / 音频 / 压缩包预览）、HTML 块、倒计时、按钮、时间轴。

Six surfaces, one file

六种编辑面，都是真实界面

下面每张截图都来自石渠 v2.2.0 本身，演示数据是虚构的。

网页复制过来，格式原样还原

从浏览器复制一段发布清单，⌘V 之后标题、列表、表格和 Rust 代码块都变成了对应的块，不用再手动整理。

写几行文字，就是流程图和公式

粘贴一段含 Mermaid 和 $$ 的 Markdown，自动生成流程图块与公式块。解析和布局都是自研的，在本机完成，不用联网。

画板：60 个模板，每个图形都能再改

思维导图、系统架构图、泳道、鱼骨图、SWOT……模板全部由普通图形组成；在文档里双击画板预览，就展开成全屏编辑器。

手绘草图，与 Excalidraw 互通

文件就是官方 .excalidraw 格式，能和 excalidraw.com、Obsidian 来回复制粘贴；箭头会绑定在图形上，拖动图形箭头跟着走。

电子表格，公式真能算

IronCalc 引擎、497 个 Excel 函数，输入 =SU 就有函数补全；数字格式、条件格式数据条，改一个数，相关格子自动重算。

一份数据，多种看法

同一批任务在表格、看板、甘特、日历之间切换；行列双向虚拟滚动，附带 10 万行压测数据。

Stays on your Mac

数据只在这台 Mac 上

石渠没有账号、没有服务器。所有内容汇进本机一个 SQLite 文件，复制整个目录就是备份。只有「网页卡片」会按需联网，可以在设置里关掉。

单线程顺序写入

所有写操作进同一个后台写线程，按提交顺序执行；退出前等写队列清空。

失败看得见

写库失败会在界面顶部提示原因，不会静默丢数据。

损坏不覆盖

文档无法解析时，原文备份到 recovery/，不会把空内容写回去。

完整备份与恢复

一键打包数据库快照和资源为 zip；恢复时旧数据移到 recovery/，不会删除。

~/Stonebrook/
├─ stonebrook.db文档、画板、表格……全部内容
├─ assets/图片与附件
└─ recovery/损坏或恢复前的原数据

Get it

下载石渠

当前版本 v2.3.0，需要 macOS 12 或更新版本。

安装包

下载对应芯片的 DMG，把「石渠」拖进「应用程序」。

Apple 芯片M1 / M2 / M3 / M4 · arm64
23.7 MB
Intel 芯片x86_64
25.7 MB

安装包使用 ad-hoc 签名，首次打开如被拦截，请到「系统设置 → 隐私与安全性」中点「仍要打开」。其他版本见 Releases。

从源码构建

需要 Rust 1.85+ 和 Xcode 命令行工具，不需要 Metal 工具链。

git clone https://github.com/davidzhanghui/stone-brook.git
cd stone-brook
# 直接运行
cargo run --release
# 打包 dist/石渠.app + DMG
scripts/build.sh

数据目录默认 ~/Stonebrook/，可用环境变量 STONEBROOK_DATA_DIR 覆盖。
